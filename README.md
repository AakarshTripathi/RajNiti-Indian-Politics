## 📖 About The Project

**RajNiti** is a web-based project designed to present political stories, timelines, and insights regarding Indian politics in an engaging and accessible format. Whether you are a student, researcher, or political enthusiast, this app provides clean content layout and seamless navigation.

---

## ✨ Features

* 📜 **Political Stories & Articles:** Read detailed pages covering key events and political history (`rajniti_india_political_story.html`).
* 🎨 **Clean & Responsive UI:** Built with standard web technologies for smooth viewing across desktops and mobile devices.
* ⚡ **Lightweight & Fast:** Pure HTML/CSS/JavaScript structure ensures instant loading times without heavy frameworks.

---

## 💻 Tech Stack

This project is built using foundational web technologies:
* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting / Deployment:** GitHub Pages
